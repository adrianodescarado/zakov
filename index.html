Posso usar meu próprio produto, não o do Scanner? +
Sim. O Scanner é só referência. No Passo 4, antes de gerar a copy, você pode editar todos os campos: nome, preço, descrição, bônus etc. Substitua pelos dados do seu produto real.
O link de compartilhamento é permanente? +
Não. O link funciona só enquanto o ZAKOV está aberto no navegador. Para link permanente, baixe o HTML e hospede no Netlify (grátis). Você recebe um link no formato nome.netlify.app que funciona para sempre.
Como colocar o link do meu checkout na página? +
Baixe o HTML, abra em qualquer editor de texto (Bloco de Notas funciona), procure por href="#" no botão de CTA e substitua pelo link do seu checkout no Hotmart, Kiwify ou outra plataforma. Salve e hospede o arquivo alterado.
A copy gerada é igual para todo mundo? +
Não. A IA gera do zero a cada vez, com base nos dados específicos do seu briefing. Mesmo usando o mesmo produto de referência, o resultado é diferente. Você também pode editar qualquer trecho diretamente na tela.
A copy ficou ruim. O que faço? +
Duas opções: 1) Clique em ✏️ Editar e corrija os trechos direto na tela. 2) Clique em ⚡ Gerar Copy com IA novamente para gerar uma versão nova (30 créditos). Tente pelo menos 2 gerações antes de editar manualmente.
Posso criar produtos em nichos diferentes? +
Sim. Ao terminar um produto, clique em "🔄 Novo produto" no Passo 6. O sistema reseta tudo e você começa do zero com 200 créditos novos.
Meu cliente recebe o ZAKOV ou só o HTML? +
Você decide. Pode: a) dar o ZAKOV para o cliente usar sozinho, b) criar os produtos pelos clientes e entregar só o HTML final, ou c) vender como serviço — cobrar pela criação e entregar a LP pronta. Os três modelos funcionam.
