❓ Como Usar
1
Escolha ou crie um produto
Clique em "Ver banco de ideias" para escolher uma referência já preenchida, ou "Criar do zero" para preencher os dados do seu produto do zero.
2
Preencha o briefing
Nome, nicho, formato, preço, descrição, dor do cliente, desejo, bônus e garantia. Todos os campos com * são obrigatórios. Se usou o banco de ideias, os campos já vêm preenchidos — ajuste conforme o seu produto real.
3
Escolha o formato
Página de Vendas: LP com 9 dobras de copy + mockups + criativos. Quiz Funnel: 8 perguntas interativas que qualificam e vendem. Você pode gerar os dois — comece por um.
4
Gere com IA
Clique em "Gerar Copy" para escrever as 9 dobras em tempo real. Depois "Gerar Mockups" para criar 5 imagens PNG reais para baixar. Por fim "Gerar 5 Criativos" para os textos de anúncio.

Você pode clicar na copy para editar o texto diretamente na tela.
5
Página Pronta
⬇️ Baixar HTML: baixa o arquivo para hospedar em qualquer servidor.
📋 Copiar HTML: copia o código para colar onde quiser.
🔗 Compartilhar: gera link temporário (funciona enquanto o ZAKOV estiver aberto).

Para link permanente: hospede no Netlify.com (grátis, arraste o arquivo e receba um link).

Meus Produtos
Cada produto finalizado é salvo automaticamente em "Meus Produtos" na topbar. Você pode baixar o HTML, visualizar ou excluir qualquer produto de lá.
